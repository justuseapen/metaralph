## Codebase Patterns
- Dashboard tabs are defined in `src/cli/dashboard.tsx` in the `TABS` array with `TabId` type union
- Tab views are React components in `src/cli/components/` named `*View.tsx`
- Footer component shows keyboard shortcuts - update when adding new tabs
- Ink library used for terminal UI - Box, Text, useInput from 'ink'
- Ink's Key type has: upArrow, downArrow, leftArrow, rightArrow, pageUp, pageDown, return, escape, ctrl, shift, tab, backspace, delete, meta
- Use `Text inverse={selected}` for selection highlighting (not backgroundColor)
- Database access via *Repository classes in `src/collaboration/`, `src/queue/`, and `src/loops/`
- Repository pattern: use `interface XRow` (snake_case) and `interface X` (camelCase), convert with `rowToX` functions
- Repositories are const objects with methods, not classes (e.g., `export const XRepository = { create(), findAll(), ... }`)
- 2-second refresh interval for real-time dashboard updates
- Anthropic SDK streaming: use `client.messages.stream()` and `stream.on('text', callback)`
- For spinners in Ink, use text-based frames (e.g., SPINNER_FRAMES array) with setInterval
