## Codebase Patterns
- Database operations use optional `db` parameter; if not provided, creates and closes connection
- Use `uuidv4()` for generating IDs
- Use ES module imports with `.js` extension even for `.ts` files
- Row-to-model conversion: database uses snake_case, models use camelCase
- Database migrations use `ALTER TABLE ADD COLUMN IF NOT EXISTS` pattern via PRAGMA table_info check
- Index naming convention: `idx_<table>_<column>`
